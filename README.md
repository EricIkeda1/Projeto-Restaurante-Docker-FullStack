# Como executar o projeto

## 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/Projeto-Restaurante-Docker-FullStack.git
```

---

## 2. Entre na pasta

```bash
cd Projeto-Restaurante-Docker-FullStack
```

---

# Executando Frontend

## Instale as dependências

```bash
cd frontend
npm install
```

---

## Rode o projeto

```bash
npm run dev
```

---

# Executando com Docker

## Subir containers

```bash
docker compose up
```
